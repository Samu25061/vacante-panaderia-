# VacantePanaderia

## Descripción
VacantePanaderia es una aplicación móvil desarrollada en Android Studio utilizando Java y XML. Su objetivo es permitir que las personas interesadas puedan postularse a una vacante de trabajo en una panadería.

## Objetivo
Desarrollar una aplicación móvil sencilla que permita ingresar los datos de una persona interesada en trabajar en una panadería y mostrar una confirmación de su postulación.

## Sector
Comercio y alimentos.

## Justificación
Las panaderías necesitan personal para realizar diferentes actividades. Una aplicación móvil facilita la recepción de los datos de las personas interesadas en trabajar y permite agilizar el proceso inicial de postulación.

## Funcionalidades
- Pantalla de bienvenida.
- Formulario de postulación.
- Ingreso de nombre completo.
- Ingreso de número de teléfono.
- Ingreso de correo electrónico.
- Confirmación de postulación.
- Visualización de los datos ingresados.
- Botón para salir de la aplicación.

## Ventanas de la aplicación
1. Pantalla principal.
2. Formulario de postulación.
3. Confirmación de postulación.
